# Saidkhuja — GitHub Pages uchun tayyor portfolio

1. ZIP faylni oching.
2. Ichidagi index.html, assets papkasi va .nojekyll faylini GitHub repozitoriyning asosiy papkasiga yuklang.
3. GitHub Pages sozlamalarida main branch va / (root) papkasini tanlang.

ZIP faylning o‘zini sayt o‘rniga yuklamang. index.html va assets bir joyda bo‘lishi kerak.

Bu tayyor sayt: npm install yoki npm run build kerak emas.
